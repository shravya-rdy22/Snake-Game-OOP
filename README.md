
# 🐍 Snake Game - Java OOP GUI

## 📖 Overview
A GUI-based Snake Game developed using Java Swing and Object-Oriented Programming (OOP) principles. The game features real-time snake movement, food generation, score tracking, collision detection, and keyboard-based controls.

## 🚀 Features
- Real-time gameplay using Java Swing
- Smooth snake movement with arrow key controls
- Dynamic food generation
- Score tracking system
- Wall and self-collision detection
- Object-Oriented Design
- Event-driven architecture using Swing Timer

## ⚙️ How It Works
1. The game starts with a moving snake.
2. Food is generated randomly on the board.
3. The snake grows whenever it eats food.
4. The score increases for each food consumed.
5. The game ends if the snake collides with a wall or itself.

## ▶️ Run Locally

```bash

```
